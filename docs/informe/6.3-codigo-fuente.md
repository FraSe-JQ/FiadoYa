# 6.3 Código fuente

El frontend utiliza TypeScript, Angular 21.2.26 y Tailwind CSS 4.1.17. Se utiliza Inter distribuida localmente. El backend utiliza Java 21, Spring Boot 3.5.7, Spring Security, OAuth2 Resource Server para JWT, Spring Data JPA, Flyway y MySQL Connector/J. big-math 2.3.2 proporciona potenciación decimal de precisión arbitraria. Springdoc 2.8.14 expone OpenAPI. Los manifiestos y archivos lock fijan las versiones.

El monorepo se divide en frontend, backend, infrastructure, docs, scripts y tests. El backend organiza los contextos por paquete; finance/domain contiene las fórmulas y application la coordinación transaccional. Los componentes Angular de autenticación, punto de venta, cuenta y rendimiento utilizan ApiService como acceso HTTP; FieldComponent y EditorComponent proporcionan ayuda y formularios reutilizables.

El motor se explica con rutas, métodos, fórmulas y pruebas en [guía de sustentación](../guia-sustentacion-codigo.md). Por ejemplo, FrenchAmortizationCalculator.installment distingue monthlyRate, accumulatedFactor, numerator y denominator; su método schedule calcula interés, amortización y saldo y ajusta la última cuota. FinancialCalculationService coordina los calculadores sin consultar la base de datos.

SalesService valida autorización, productos, moneda, modalidad, plazo, crédito y límites de tasas; después guarda compra, ítems y obligaciones. PaymentService obtiene la liquidación, exige importe exacto e invoca PaymentAllocationCalculator. Data centraliza operaciones JPA. La configuración de seguridad se encuentra en iam/infrastructure/SecurityConfig.java y el inicio de sesión en AuthController.

Swagger se consulta en /swagger-ui/index.html y OpenAPI en /v3/api-docs. La instalación se documenta en README.md y despliegue.md. Los recorridos de compra y pago están en [diagramas de secuencia](../trazabilidad-operaciones.md). La evidencia de pruebas pertenece a resultados-pruebas.md; no se deducen resultados de la existencia de código de prueba.
